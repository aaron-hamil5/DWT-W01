# <img src="https://www.uniqstudio.org/images/template_web.webp" alt="TEMPLATE Logo" width="25"/> Dynamic Web Technologies - JavaScript Refresher

The primary objective of this lab session is to reinforce your fundamental understanding of JavaScript, which is crucial for upcoming React JS sessions. We'll focus on solidifying your knowledge of core JavaScript elements, such as variables, data types, and operators. You'll also enhance your proficiency in creating and using functions, a skill pivotal for managing React components and event handling.

## ✨ Features
- **Development Environment**
    > We will be selecting our preferred development environment and setting the environment up, ready for the final coursework.
- **GitHub Account**
    > Setting up an account with GItHub to host our work and learning the fundamentals as our final coursework will be hosted on GitHub.
- **JavaScript Fundamentals**
    > Revisiting the fundamentals of JavaScript, focusing on the aspects that are necessary for React

## 🛠️ Tech Stack
- **Languages**: HTML5, CSS3, JavaScript
- **Frameworks**: Plain HTML/CSS
- **Version Control**: Git / GitHub

## 🚀 Deployment
Deploy Project Locally:
1. Download the project
2. Unzip the package
3. Within the unzip folder, look for index.html
4. Launch it with your preferred browser

   > For the best outcome, use VSCode or WebStorm and use LiveServer to host the project.
